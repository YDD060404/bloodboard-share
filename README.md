# Bloodboard Unified 0.2.0

[Play locally in your browser](https://ydd060404.github.io/bloodboard-share/) · [Hosted multiplayer](https://bloodboard-match.onrender.com/) · [Download](https://github.com/YDD060404/bloodboard-share/releases/latest)

The browser page supports local games, AI opponents, team building, and replays. Use the hosted multiplayer address for online games with a friend. This repository is a clean runtime distribution, not the private development history.

Bundled AIs: Balanced, frozen Hopeful 1.5.9, and Hopeful S4.37U. The latest compatibility build retains its trained weights; no claim of superior playing strength is made. It combines the cloud UI/network repairs with the accepted local ball-chain and state-key optimizations.

To run the downloaded package offline, unzip it and open index.html. Alternatively, install Node.js18+, run `npm start` in this folder, then open http://127.0.0.1:8790 . Local browser saves stay in that browser profile. Native Mac release uses the existing Bloodboard data locations and includes rollback instructions.

Refresh both clients after online updates. Never clear site storage to reconnect: it holds your seat token. The hosted service is one shared room on a free plan and can need time to wake. Two-device internet gameplay has not been newly certified in this release.

See RELEASE_NOTES.md, build-info.json and SHA256SUMS for version evidence. No credentials, personal matches, rulebook PDFs, or private history are included. Unofficial personal tool, not affiliated with Games Workshop.

# Bloodboard Unified 0.2.0

One source core for the native Mac app, standalone browser, hosted match server and Match Lab. Acceptance results are recorded separately; this file describes the intended changes.

- Retains Online 0.1.10 Glotl Stop activation continuation repairs, queued remote playback, durable room recovery, 60-second full-time archival, Chinese/English, keyboard controls, both board orientations and sidelines.
- Adds the accepted local exact ball-chain solver/cache, exact canonical-key loops, actual rules edition in AI observations, and a UTF-8-aware 256 KiB diagnostic trace cap.
- Keeps frozen Balanced and Hopeful 1.5.9. Hopeful S4.37U is a separately identified compatibility build with unchanged training receipts and model weights. It is not a newly trained stronger model. Unaccepted S4.38–S4.41 experiments are excluded.
- New source fingerprints are generated honestly. Old saves/history may be labelled as coming from different rules code. No live journals, teams, settings, imported coaches or credentials are reset during installation.

No 30× whole-match speedup or superiority to 1.5.9 is claimed. Local browser integration checks do not establish a two-physical-device internet match. Native binaries are locally signed; macOS may require the normal first-open action on a different computer.
